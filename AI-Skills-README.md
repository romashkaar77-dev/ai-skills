## Использование без Termux

1. Откройте каталог в ChatGPT или GitHub.
2. Выберите навык и попросите ChatGPT прочитать оригинальный SKILL.md и необходимые ссылки.
3. Для исполнения скриптов используйте совместимую среду Codex; проверьте доступность инструментов, лицензии и зависимости.
4. Не публикуйте ключи API, токены и файлы .env. Не выполняйте непроверенные скрипты. Изменения исходных проектов — только по согласованию.

Хранение каталога в GitHub не устанавливает навыки автоматически.
